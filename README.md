Paws & Hope Animal Rescue

 1. Project Overview

Paws & Hope Animal Rescue is a non-profit animal rescue organisation based in Limpopo. The organisation helps abandoned, neglected and vulnerable animals by providing care, support and assistance in finding safe and permanent homes.

The website was developed to provide information about the organisation, its services and the ways in which visitors can make enquiries or get in contact.


 2. Website Pages

The website consists of five main HTML pages:
Page  File  Main Purpose 

 Home  `index.html` Introduces Paws & Hope Animal Rescue 
About Us  `about.html`  Provides information about the organisation 
 Services `services.html`  Describes the services provided 
 Enquiry `enquiry.html` Allows visitors to submit an enquiry 
Contact `contact.html`  Provides contact and location information
